# 🐾 PM3 - Gestión de turnos veterinaria

Proyecto académico individual de la formación en **SoyHenry**.  
El objetivo fue construir un proyecto **Full Stack** (frontend + backend) para la **gestión de turnos de una veterinaria**, consolidando conocimientos de React, Redux y PostgreSQL.

## 🚀 Tecnologías
- **Frontend:** React, Formik, Vite, Axios, CSS (module)  
- **Backend:** Node.js (Express), Morgan
- **Base de datos:** PostgreSQL + TypeOrm 
- **Control de versiones:** Git / GitHub  

## ⚙️ Funcionalidades principales
- Registro y gestión de usuarios (clientes y veterinarios).  
- Creación, modificación y eliminación de turnos.  
- Panel de control para visualizar turnos disponibles.  
- Filtrado y ordenamiento de turnos.  
- Manejo de estados globales con React.

## 🛠️ Instalación
1. Clonar el repositorio  
   ```bash
   git clone https://github.com/maticassagne/PM3-Henry.git
2. Instalar dependencias en /front y /back:
   ```bash
   cd front && npm install
   cd ../back && npm install
3. Configurar las variables de entorno (.env) para la base de datos.
4. Ejecutar el backend y frontend en paralelo:
   ```bash
   npm start
